# Ambiguity sweep

Could two reasonable implementations satisfy the wording? Check undefined terms,
conflicting requirements, hidden assumptions, actors, boundary/error behavior, scope
and unmeasurable quality claims. Cite the requirement or task passage behind each finding.

State a reasonable assumption for low-impact details. Ask about material behavioral forks
before dependent work. A deferred question needs an owner and revisit trigger/date;
uncertainty changing the contract cannot pass its dependency boundary. Do not add scope,
redefine canonical terms, ask a question per finding, or require another agent routinely.
